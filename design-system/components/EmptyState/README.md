空狀態分兩種，邊框不同。

**篩選無結果**長在清單原本的位置，所以沿用清單的框：上緣 2px `ink`、下緣 1px `line`，沒有虛線。它一定要附一個把使用者拉回去的按鈕（「清除條件」），而且說明要講清楚「改什麼會有結果」——「把地區或教練改回『不指定』，就能看到全部六個時段」，不要只說「查無資料」。

**尚未操作**（查詢頁還沒按查詢）用 1px `accent-line` 虛線框加 `radius-field`。虛線表示「這裡等一下會有東西」。它不需要按鈕，因為動作就在上面那張表單裡。

圖示用羽球，64–72px，`accent` 填色加 2px `ink` 描邊。這是全系統唯一的插圖，畫面裡只出現一次。**目前這顆羽球是用幾何畫的暫用示意，不是正式資產。**

標題 18px／700，說明 13px 配 `ink-muted`，置中，垂直間距 `space-3`。

錯誤狀態不要用空狀態處理——錯誤要留在出錯的欄位旁邊。

消費端要提供：清空後的焦點處理（按下「清除條件」後把焦點送回篩選器）、圖示的 `aria-hidden`。
