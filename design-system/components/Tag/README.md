三種小型顯示元件，界線要分清楚。

**分類標籤**是有外框的小方塊：12px 字、2px／7px 內距、1px `ink` 外框、`radius-control`。用在「季課程」「單堂」這類不會變的屬性。需要更明顯時填 `accent-tint`，不要填 `accent`——那是按鈕的顏色。

**狀態**不是標籤，是**有顏色的文字**：14px、500 字重、`success`／`warning`／`danger`，沒有底色也沒有外框。名額、付款狀態、發票狀態全部用它。彩色藥丸會和 `accent` 的主要按鈕打架，一整欄排下來也會看起來像一排可按的東西。

狀態一定要把話寫完：「剩 2 個名額」而不是一個橘點，「已取消」而不是一條刪除線。顏色是輔助，文字才是資訊。

**統計數字**是上緣一條 2px `border-rule`、上面一行 `caption` 標籤、下面一個 `num` 字級的大數字。後台的概況列用它，四個一排。數字本身可以帶狀態色（待付款用 `warning`、待開發票用 `danger`），標籤維持 `ink-muted`。

金額、數量、日期一律用 `num`（Barlow Condensed），中文標籤維持 `sans`。

消費端要提供：狀態的文字內容（不可只給顏色）、統計數字的單位。
