容器有三種，差別在「用什麼把它和旁邊分開」，不在圓角或陰影。

**清單列**是最常用的一種：整份清單上緣一條 2px `ink` 的 `border-rule`，每列下緣一條 1px `line` 的 `border-hair`，列本身沒有底色也沒有外框。課程、時段、訂單、教練、館別全部用這個。左欄固定寬放時間或日期（用 `num` 字級），中間彈性放名稱與說明，右側放動作。

**說明區塊**用 `accent-tint` 底加 1px `accent-edge` 外框、`radius-field` 圓角。只給需要被讀完的那一段話：發票說明、系統規則、金額摘要。一個畫面最多兩個，多了就變成滿版色塊。

**摘要卡**是說明區塊加一條 2px `border-rule` 分隔線，線下放總計金額（`num-xl` 或 32px）。結帳頁右欄用它。

三種都**不使用陰影，不使用大圓角**。想讓一塊區域更突出時，加線或加字重，不要加底色——白底上再疊一層灰底是這套風格最常見的破壞方式。

卡片內距用 `space-4` 到 `space-5`；清單列上下內距 `space-4`，桌機表格列可縮到 12px。

消費端要提供：列的語意結構（清單用 `ul`／`li` 或表格用 `table`）、每列動作的無障礙名稱。
