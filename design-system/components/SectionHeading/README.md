標題有兩個層級，分別靠「帶狀」與「2px 線」做，不靠字級大小硬撐。

**帶狀頁首**是每一頁最上面那塊 `accent`，下緣一條 1px `accent-line`。裡面由上而下是：`overline`（全大寫英文，`ink-on-band`）、`display` 主標（900 字重）、一行 `body` 說明（`ink-on-band`）。手機左右內距 `space-5`，桌機 `space-7`，後台 `space-6`。篩選用的下拉選單也放在帶狀裡，跟著主標一起走。

一頁只有一個帶狀頁首，也只有一個 `display`。

**區塊標題**是 18px／700 的 `title`，下方一條 2px `ink` 的 `border-rule`。右側可以放一個東西：英文對照（`eyebrow`，`ink-muted`）**或**一則狀態（`success`／`warning`／`danger`），不要兩個都放。

2px 線是這套風格切分版面的主要工具。需要再往下一層時用 17px 的 `heading`，**不加線**——不要出現第三條不同粗細的線。

上一版的螢光筆底線與手寫體副標已隨風格退場，不要再用。

消費端要提供：正確的標題階層（`h1` 只有一個，區塊用 `h2`）、帶狀區的 `overline` 純裝飾不進大綱。
