導覽有兩種形態，共用同一塊 `accent` 底。

**前台頁首導覽**在帶狀最上面那 72px（手機 56px）：品牌名 900 字重、右邊接 `BADMINTON` 英文小標（`num` 字級、字距 0.18em、`ink-on-band`），然後是頁面連結，最右是諮詢專線。目前頁用 2px `ink` 底線，同時把文字換成 `ink` 與 700 字重。

**後台側欄**是 236px 寬的 `accent` 直欄，右緣 1px `accent-line`。上方是品牌名加 `ADMIN CONSOLE`，中間是模組連結（44–46px 高），最下方是管理員資訊與登出。目前頁改成 `surface-card` 白底加 `inset 3px 0 0 ink` 的內側色條——側欄本身就是淺藍，底線在上面看不出來。

兩種形態的目前頁都**同時改三件事**：底線或色條、字色（`ink-on-band` → `ink`）、字重（400 → 700）。只靠一個記號，在淺藍底上辨識度不夠。

未選中的連結用 `ink-on-band`，這是它在 `accent` 上唯一達標的次要色。

上一版的六宮格功能磚（大圓角、粗描邊、貼紙陰影）已經退場，簡約 B 不使用功能磚。

消費端要提供：`nav` 語意、目前頁的 `aria-current="page"`、側欄在窄螢幕的收合行為。
