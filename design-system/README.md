弘淇羽球訓練中心的介面語彙來自 LOGO 那抹藍。第一版走的是手繪貼紙風，客戶看過後覺得太可愛，2026 年 9 月改為「簡約 B」定案。這一版守三個字——**淡、直、清**。淡是淺藍 `accent` 只鋪在頁首帶狀與主要按鈕上，其餘一律留白；直是圓角收到 2px、沒有膠囊也沒有陰影；清是層級全靠線條與字重做，不靠色塊堆疊。報名、繳費、對帳這些事看起來要俐落，不要可愛。

## 語氣與文案

對使用者說「你」，對中心說「我們」。按鈕用動詞開頭的短句：「立即報名」「查看場次」「前往付款」；按下後的回饋用完成式：「已完成報名」。錯誤訊息說清楚哪裡不對、怎麼修——「這個條件沒有開放時段，把地區或教練改回『不指定』」——不道歉、不模糊。

英文只出現在 `overline` 與 `eyebrow` 兩個字級（`AUTUMN 2026`、`ORDER NO.`），全大寫、字距放寬，作用是給版面一條水平線和一點節奏，**不承載必讀資訊**。不使用 emoji，不使用手寫體。

## 色彩

版面底色是 `surface-page`（純白）。層次不靠底色深淺做，靠線條與字重做——這是它和第一版最大的差別，也是最容易被改壞的地方：想要區隔某一區時，先試 2px 的 `border-rule`，不要加一塊灰底。

`accent` 是唯一的品牌色，只出現在三個地方：頁首帶狀、主要按鈕、選中的月曆日期（後台側欄算頁首帶狀的延伸）。它是**填色，不可當文字色**。落在它上面的主要文字用 `ink-on-accent`（深藍，不是白字），次要文字用 `ink-on-band`。

每一頁最上面那塊帶狀用 `band`——`accent` 的 50%，實作寫 `rgba(179, 217, 236, 0.5)`。帶狀要比主要按鈕退後一階，不然滿版的淺藍會把按鈕吃掉；後台側欄不在「上面」，維持全強度 `accent`。

白底上的次要文字用 `ink-muted`；`ink-on-band` 只在 `band` 與 `accent` 上用，白底上不要拿它當內文色。需要一塊淺底時用 `accent-tint`，外框配 `accent-line`。

狀態色 `success`／`warning`／`danger` 與 `accent` 分開，不可互相代用。狀態一定同時出現文字，不靠顏色單獨判讀——「剩 3 個名額」比一個橘點清楚得多。

## 字體

中文用 `sans`：Noto Sans TC → PingFang TC → Microsoft JhengHei。**標題一律一般字重（400），不加粗。** 層級交給字級、2px 底線與留白；需要強調時加線，不要加粗。粗體只留給按鈕、狀態文字與需要被挑出來的關鍵詞。

**數字、金額、時間、日期、訂單編號一律用 `num`（Barlow Condensed）。** 這是風格的另一半：窄體數字讓「19:00–21:00」「NT$4,800」在窄欄位裡站得住，而且和中文黑體並排時對比明顯。中文不要用 `num`。

內文用 `body`，關鍵詞用 `body-strong`，補充說明用 `caption` 搭 `ink-muted`，表單標籤用 `label`。

## 形狀與線條

圓角只有兩個值：控制項 `radius-control`（2px）、輸入框與說明區塊 `radius-field`（4px）。沒有膠囊，沒有 20px 以上的圓角。

線條分兩級，沒有第三種：

- `border-rule`（2px）配 `ink`——區塊標題下緣、表格表頭下緣、統計數字上緣。這是層級線。
- `border-hair`（1px）——按鈕與輸入框外框配 `ink`，清單列之間配 `line`，頁首帶狀下緣配 `accent-line`。這是結構線。

**不使用陰影。** 唯一的例外是選中的月曆日期用 `inset 0 0 0 2px` 的 ink 內框，因為淺藍底上如果只靠填色，選中與未選中幾乎看不出差別。

## 按鈕的外框不能拿掉

主要按鈕是「`accent` 填色 **加** 1px `ink` 外框」。淺藍在白底上單獨出現時邊界會糊掉，外框是刻意保留的結構，不是多餘裝飾。次要按鈕是白底加同一道外框，危險動作把外框與文字換成 `danger`。停用狀態改成 `surface-sunken` 底、`ink-disabled` 字、**不留外框**——這是唯一可以沒有外框的按鈕狀態，因為它本來就不該看起來可按。

## 對比

深藍 `ink` 壓在 `band` 上是 14.4:1、在 `accent` 上是 11.7:1，`ink-on-band` 在 `band` 上是 6.9:1、在 `accent` 上是 5.6:1，`ink-muted` 在白底上是 5.9:1，三個狀態色在白底上都在 4.7:1 以上，全部過 WCAG AA。

唯一低於 4.5:1 的是 `ink-off`（月曆上沒開課的日期，約 2.3:1）與 `ink-disabled`（停用控制項）。兩者都是不可操作的元素，且旁邊一定有可讀的說明——不要拿它們寫任何需要被讀到的字。

## 圖示

線性圖示，2px 描邊，端點用 `stroke-linecap: square`（不是 round，圓端點會拉回上一版的可愛感），顏色用 `currentColor`。尺寸 14／16／24 三階。

**目前系統內沒有官方圖示檔，也沒有吉祥物檔。** EmptyState 與 Cover 預覽裡的羽球是用幾何畫的暫用示意。上一版的吉祥物出場規則已隨風格一起退場——簡約 B 不使用吉祥物。

## 動態

hover 只換顏色（`accent` → `accent-deep`），不位移、不縮放。按下時不做任何位移。轉場 120–160ms、線性或 ease，不用彈跳曲線。尊重 `prefers-reduced-motion`：關掉所有轉場。

## 這套系統目前交付的是 CSS 樣式規範

各元件沒有 JS bundle，每個 `preview.html` 就是可直接抄走的 HTML／CSS 寫法，全部只用本系統的 token。接到實際專案時，把這些樣式接成你框架裡的元件即可。對應的介面稿在「弘淇羽球報名系統」畫布裡，前台手機 5 張、前台桌機 5 張、後台 5 張。
